Make a magic ring.
Round 1: Ch 5; (tr in ring, ch 1) 15 times. Join with sl st to 4th ch of ch-5 (16 sps made).
Round 2: * 2 s c in next sp, s c in next tr. Repeat from * around, ending with s c in sl st.
Round 3: Sl st in next s c, ch 3, d c in next s c, * ch 2, skip 1 s c, d c in next 2 s c. Repeat from * around, ending with ch 2, sl st in 3rd st of ch-3.
Round 4: Sl st between ch-3 and next d c, ch 3, * d c between next 2 d c, ch 3, d c in same place as last d c. Repeat from * around, ending with d c in same place as sl st, ch 3, sl st in 3rd ch of ch-3.
Round 5: S c between ch-3 of previous rnd and 1st d c, * 3 s c in next ch-3 sp, s c between next 2 d c. Repeat from * around, ending with 3 s c in last ch-3 sp, sl st in 1st s c.
Round 6: Ch 7, skip 3 s c, s c in next s c, ch 4, skip 3 s c, s c in next s c, * ch 4, skip 3 s c, d c in next s c, ch 4, d tr in same place as last d c, skip 3 s c, d tr in next s c, ch 4, d c in same place as last d tr; (ch 4, skip 3 s c, s c in next s c) twice. Repeat from * around, ending with d tr in same place where ch-7 started, ch 4, sl st in 3rd ch of ch-7.
Round 7: Ch 5, s c in 1st sp, ch 2, d c in next s c (a lacet made). * Ch 4, d c in next s c (a bar made); ch 2, s c in next ch-4, ch 2, d c in next d c (another lacet); 6 d c in next sp. Between next 2 d tr make 3 d c, ch 5 and 3 d c; 6 d c in next sp, d c in next d c, ch 2, s c in next ch-4, ch 2, d c in next s c. Repeat from * around, ending with 6 d c in last ch-4 sp. Join to 3rd st of ch-5.
Round 8: Ch 7, d c in next d c (bar made over lacet); * ch 2, s c in next ch-4, ch 2, d c in next d c (lacet made over bar). Ch 4, d c in next 10 d c; in corner ch-5 make 2 d c, ch 5 and 2 d c; d c in next 10 d c, ch 4, d c in next d c. Repeat from * around; join.
Round 9: Ch 5, s c in next ch-4, ch 2, d c in next d c, * bar over next lacet, lacet over next bar, d c in each d c across to within corner; in corner ch-5 make 2 d c, ch 5 and 2 d c; d c in each d c across next d c-group; lacet over bar. Repeat from * around, ending with d c in each d c of d c-group, sl st to 3rd st of ch-5.
Round 10: Ch 7, * 1 bar, 1 lacet, 1 bar, ch 2, skip 1 d c, s c in next d c, ch 2, skip 1 d c, d c in next d c, ch 4, skip 4 d c, d c in next d c; ch 2, skip 1 d c, s c in next d c, ch 2, skip 1 d c, d c in next d c, 2 d c in corner sp, d c in 3rd ch of same corner, ch 5, d c in same place as last d c, 2 d c in same corner sp, d c in next d c. Ch 2, skip 1 d c, s c in next d c, ch 2, skip 1 d c, d c in next d c, ch 4, skip 4 d c, d c in next d c, ch 2, skip 1 d c, s c in next d c, ch 2, skip 1 d c, d c in next d c. Repeat from * around. Join last ch-2 to 3rd st of ch-7.
Round 11: (1 lacet, 1 bar) 3 times; * d c in next 3 d c, 2 d c in corner sp; in center ch of same corner make d c, ch 5 and d c; 2 d c in same corner sp, d c in next 4 d c; (1 bar, 1 lacet) 4 times, 1 bar. Repeat from * around. Join last ch-4 to 3rd ch of ch-5.
Round 12: (1 bar, 1 lacet) 3 times, * d c in each d c across d c-group; make corner as before, d c in each d c across remaining d c of group; (1 lacet, 1 bar) 4 times; 1 lacet. Repeat from * around; join. Corners of 10th, 11th and 12th rnds form corner pattern, which is repeated 5 times in all.
Round 13: (1 lacet, 1 bar) 3 times; 1 lacet and 1 bar over one side of d c-group as before, 2 d c in corner sp; in 3rd ch of corner ch-5 make d c, ch 5 and d c; 2 d c in same corner sp, d c in next d c, 1 bar and 1 lacet over other side of d c-group. Continue thus around, making bar over lacet and lacet over bar, making other corners as before.
Round 14-17: Make bar over lacet and lacet over bar, working corner pattern as before.
Round 18: Ch 7, d c in next d c, * 4 d c in next ch-4 sp, d c in next d c; (1 bar, 1 lacet) 4 times; work corner as before; (1 lacet, 1 bar) 4 times. Repeat from * around; join.
Round 19: Ch 3, * 3 d c in next ch-4, d c in next 6 d c; 3 d c in next ch-4, d c in next d c; (1 bar, 1 lacet) 3 times; 1 bar, then make 1 lacet and 1 bar across one side of d c-group; start another d c-group at corner as before, and make a bar and lacet across other side of d c-group; (1 bar, 1 lacet) 3 times; 1 bar. Repeat from * around; join.
Round 20: Ch 3, * d c in each d c across d c-group, 3 d c in next ch-4, d c in next d c; (1 bar, 1 lacet) 4 times. Work corner as before; (1 lacet, 1 bar) 4 times; 3 d c in next ch-4 sp. Repeat from * around, ending with 3 d c in last ch-4 sp; join.
Round 21: Ch 3, * d c in each d c across d c-group, 3 d c in next ch-4, d c in next d c; (1 bar, 1 lacet) 3 times; 1 bar. Make corner as before; (1 bar, 1 lacet) 3 times; 1 bar; 3 d c in next ch-4. Repeat from * around; join.
Round 22: Ch 3, d c in next 17 d c, * ch 4, skip 3 d c, d c in next d c; (1 lacet, 1 bar) 3 times; 1 lacet; then make 1 bar and 1 lacet across one side of d c-group. Make corner as before, 1 lacet and 1 bar across other side of d c-group; (1 lacet, 1 bar) 4 times; d c in next 22 d c. Repeat from * around, ending with ch 4, skip 3 d c, d c in last 4 d c; join.
Round 23: Ch 3, d c in next 13 d c; * (1 bar, 1 lacet) 5 times; 1 bar, make corner as before; (1 bar, 1 lacet) 5 times; ch 4, skip 3 d c, d c in next 14 d c. Repeat from * around; join last ch-4 to 3rd ch of ch-3.
Round 24: Ch 6, * skip 3 d c, d c in next 6 d c, ch 3, skip 3 d c, d c in next d c; (ch 3, d c in next d c) 11 times; make corner as before; (ch 3, d c in next d c) 11 times; ch 3. Repeat from * around; join and fasten off.
